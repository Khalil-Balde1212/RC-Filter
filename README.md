# RC Filter Example Codes

This repository contains example Python scripts for simulating and analyzing RC (Resistor-Capacitor) filters. The code demonstrates how to generate noisy input signals, model RC filter behavior, and analyze the filter's response to sine waves.

## Files

- **NoisyInput.py**: Generates a noisy input signal for testing the RC filter.
- **RCFilterModel.py**: Contains the implementation of the RC filter model.
- **SinewaveResponse.py**: Analyzes the RC filter's response to a sine wave input.
